E-LKPD Interaktif: Larutan Elektrolit & Non-Elektrolit

Temukan konsep daya hantar listrik larutan, reaksi ionisasi Arrhenius, dan pengaruh ikatan kimia melalui tahapan penyelidikan ilmiah berbasis Guided Inquiry Learning.

Tujuan Pembelajaran

  • Mengidentifikasi gejala daya hantar listrik larutan berdasarkan nyala lampu dan gelembung gas pada elektroda.
  • Mengelompokkan larutan ke dalam elektrolit kuat, elektrolit lemah, dan non-elektrolit berdasarkan data percobaan.
  • Menjelaskan penyebab kemampuan larutan menghantarkan arus listrik menurut Teori Ion Svante Arrhenius.
  • Menganalisis hubungan jenis ikatan kimia (ionik dan kovalen polar) dengan daya hantar listriknya dalam wujud padatan, lelehan, dan larutan.

Sintaks 1 • Guided Inquiry

Orientasi Peserta Didik pada Fenomena

⚡ Fenomena Kontekstual

Mengapa Tangan Basah Berisiko Tersengat Listrik, Sedangkan Air Suling Murni Tidak Menghantarkan Listrik?

Di rumah, kita sering diperingatkan agar tidak menyentuh sakelar atau peralatan listrik saat tangan basah karena berisiko tersengat arus listrik. Begitu pula penangkapan ikan menggunakan alat setrum di sungai sangat berbahaya karena air sungai dapat menghantarkan listrik.

Namun, tahukah kamu bahwa ketika air suling murni (akuades / H₂O) diuji di laboratorium dengan rangkaian penguji elektroda, lampu bohlam ternyata padam dan tidak muncul gelembung gas? Sebaliknya, ketika ke dalam air suling ditambahkan satu sendok garam dapur (NaCl) atau asam cuka (CH₃COOH), fenomena yang berbeda terjadi!

Informasi Pendukung (Teori Ion Svante Arrhenius)

Pada tahun 1887, ilmuwan Swedia Svante August Arrhenius mengemukakan bahwa zat elektrolit ketika dilarutkan dalam air akan terdisosiasi (terionisasi) menjadi partikel-partikel bermuatan listrik positif (kation) dan negatif (anion) yang bergerak bebas.

Tidak Terionisasi
α = 0

/**
 * FILE: google_apps_script.gs
 * Database Google Sheets untuk Penelitian Skripsi E-LKPD Guided Inquiry
 * Materi: Larutan Elektrolit dan Non-Elektrolit
 */

const SHEET_NAME = 'Data_Nilai_ELKPD';

function setupSheet() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(SHEET_NAME);
  if (!sheet) {
    sheet = ss.insertSheet(SHEET_NAME);
  }
  if (sheet.getLastRow() === 0) {
    sheet.appendRow([
      'Timestamp Server',
      'Waktu Selesai Siswa',
      'Nama Lengkap',
      'Kelas',
      'Nomor Absen',
      'Nilai Akhir (0-100)',
      'Jumlah Benar (dari 20)',
      'Jumlah Salah',
      'Ketepatan Tabel Pengamatan (%)',
      'Status Rumusan Masalah & Hipotesis',
      'Detail Jawaban 20 Soal PG (JSON)'
    ]);
    sheet.getRange(1, 1, 1, 11).setFontWeight('bold').setBackground('#e0e7ff');
  }
}

function doPost(e) {
  const lock = LockService.getScriptLock();
  lock.tryLock(10000);

  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    let sheet = ss.getSheetByName(SHEET_NAME);
    if (!sheet) {
      setupSheet();
      sheet = ss.getSheetByName(SHEET_NAME);
    }

    const rawBody = e.postData ? e.postData.contents : '{}';
    const data = JSON.parse(rawBody);

    sheet.appendRow([
      new Date(),
      data.waktuSelesai || '',
      data.namaLengkap || '',
      data.kelas || '',
      data.nomorAbsen || '',
      Number(data.nilaiAkhir) || 0,
      Number(data.jumlahBenar) || 0,
      Number(data.jumlahSalah) || 0,
      data.skorObservasiPersen || '0%',
      data.statusInkuiri || '',
      JSON.stringify(data.jawabanPG || {})
    ]);

    return ContentService
      .createTextOutput(JSON.stringify({ status: 'success', message: 'Data E-LKPD berhasil disimpan' }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'error', message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}
